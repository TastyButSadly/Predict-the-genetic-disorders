# Predict-the-genetic-disorders


# Описание столбцов таблицы пациентов

## Основная информация
| Название столбца | Описание |
|------------------|----------|
| **Patient Id** | Идентификационный номер пациента. |
| **Patient Age** | Возраст пациента. |
| **Patient First Name** | Имя пациента. |
| **Family Name** | Фамилия пациента. |
| **Gender** | Пол пациента. |
| **Status** | Статус пациента (жив ли пациент). |

## Генетическая информация
| Название столбца | Описание |
|------------------|----------|
| **Genes in mother's side** | Наличие генетического дефекта у матери пациента. |
| **Inherited from father** | Наличие генетического дефекта у отца пациента. |
| **Maternal gene** | Наличие генетического дефекта по материнской линии семьи. |
| **Paternal gene** | Наличие генетического дефекта по отцовской линии семьи. |
| **Genetic Disorder** | Наличие генетического расстройства у пациента. |
| **Disorder Subclass** | Подкласс генетического расстройства. |

## Медицинские показатели
| Название столбца | Описание |
|------------------|----------|
| **Blood cell count (mcl.)** | Количество кровяных клеток у пациента. |
| **White Blood cell count (thousand per microliter)** | Количество белых кровяных клеток у пациента. |
| **Blood test result** | Результаты анализа крови пациента. |
| **Respiratory Rate (breaths/min)** | Частота дыхания пациента. |
| **Heart Rate (rates/min)** | Частота сердечных сокращений пациента. |

## История беременности и родов
| Название столбца | Описание |
|------------------|----------|
| **Birth asphyxia** | Наличие асфиксии при рождении. |
| **Autopsy shows birth defect (if applicable)** | Наличие врождённых дефектов по результатам вскрытия (если применимо). |
| **Place of birth** | Место рождения пациента (медицинское учреждение или дом). |
| **Folic acid details (peri-conceptional)** | Подробности приёма фолиевой кислоты в периконцепционный период. |
| **H/O serious maternal illness** | Наличие серьёзных заболеваний у матери во время беременности. |
| **H/O radiation exposure (x-ray)** | Наличие истории облучения (рентген). |
| **H/O substance abuse** | Наличие истории злоупотребления наркотиками у родителей. |
| **Assisted conception IVF/ART** | Использование методов лечения бесплодия (ЭКО/ВРТ). |
| **History of anomalies in previous pregnancies** | Наличие аномалий в предыдущих беременностях матери. |
| **No. of previous abortion** | Количество предыдущих абортов у матери. |
| **Birth defects** | Наличие врождённых дефектов у пациента. |

## Информация о родителях
| Название столбца | Описание |
|------------------|----------|
| **Father's name** | Имя отца пациента. |
| **Mother's age** | Возраст матери пациента. |
| **Father's age** | Возраст отца пациента. |

## Информация о медицинском учреждении
| Название столбца | Описание |
|------------------|----------|
| **Institute Name** | Название медицинского учреждения, где родился пациент. |
| **Location of Institute** | Местоположение медицинского учреждения. |

## Тесты и симптомы
| Название столбца | Описание |
|------------------|----------|
| **Test 1 - Test 5** | Результаты различных (замаскированных) тестов, проведённых у пациента. |
| **Symptom 1 - Symptom 5** | Различные (замаскированные) симптомы, наблюдаемые у пациента. |

## Дополнительная информация
| Название столбца | Описание |
|------------------|----------|
| **Parental consent** | Согласие родителей на план лечения. |
| **Follow-up** | Уровень риска пациента (степень тяжести состояния). |
